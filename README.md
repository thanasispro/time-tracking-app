# Time Tracking App

This project is a time tracking application built with React and TypeScript. It allows users to track their time spent on various activities and view reports on a daily, weekly, and monthly basis.

## Features

-   Track time spent on different activities (Work, Play, Study, Exercise, Social, Self Care).
-   View reports on daily, weekly, and monthly timeframes.
-   Responsive design for different screen sizes.

## Technologies Used

-   React
-   TypeScript
-   Tailwind CSS
-   Vite
